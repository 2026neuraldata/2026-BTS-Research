## 이번 단계에서 보류할 기능

- 센서 자동 연동, PAC/Alum 실험 확대, 전면 Local LLM 이전, 실험 DB 자동 수정, 슬러지 자원화는 포스터 필수 범위에 추가하지 않는 안임.
- AI 추론 에너지는 계측·장비·호출량 기준이 없으면 정량값을 생성하지 않음.
- 지역 비교는 기존 그림·조건표로 먼저 구성하고 지도 상호작용 확대는 후순위로 둠.
- 포스터의 ‘novelty’는 외부문헌 대비 새로움 검증과 구별함. 현재 분석의 내부 검증만으로 세계 최초 또는 메커니즘 규명을 주장하지 않음.
