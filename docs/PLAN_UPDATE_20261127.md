## 실행 차단 조건

- C03/L04의 실제 모델·공통 설정·자료 범위·접근통제 시험 통과 및 C05 심사 설정 동결·실제 노출 이력 확인 후 L06 시작. L06에서 저장된 동일 답변으로 L07 시행. 조건 미충족 시 최종 실행 금지, 미실행/부분 결과와 한계 기록. G04·포스터는 일정대로 실제 확보한 결과만 활용함.
- L03 예비 비교의 기준점수 편중 및 LLM 보조 후 사람 승인 한계를 기록하고 L05에서 독립 채점을 수행함. 보정 및 별도 검증 자료 부족 시 DSPy 생략·수동 경로 유지. 최종 답변을 본 뒤 모델·프롬프트를 변경하지 않음.
- [접근 통제](EVALUATION_ACCESS_CONTROL.md)는 실제 후보 모델 실행 계정·검색·도구·세션을 검증해야 함. GitHub 공개 파일 제외만으로 보안 검증을 대체할 수 없음. 비공개 평가 자료 및 내부 로그는 공개 저장소에 업로드하지 않음.
- C07의 발표 외부 URL/QR 여부는 G03에서 결정; 로컬 시연·영상 백업은 유지. 일정 및 업무 범위 변경은 실제 회의에서 결정할 것.
