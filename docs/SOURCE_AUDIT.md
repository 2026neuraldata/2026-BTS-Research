## 완료 범위를 과장하지 않기 위한 구분

- 모든 파일의 존재·접근·내용 추출·연구상 역할을 확인했음. 다만 교과서2권의 모든 문장과 수식, 모든 도판을 정밀하게 검증한 것은 아님. 전권 텍스트를 추출하고 응집·평가문항·에너지 관련 부분을 중점 검토함.
- 음성의 일부 문장·고유명사·발언자는 자동전사만으로 확정할 수 없음. 해당 부분을 새 일정·담당·과학적 수치의 단독 근거로 사용하지 않음.
- 개발 보고서는 읽었지만 app.py·logic.py·실제 API 실행 로그는 현재 Drive에 없음. 현재 앱 동작을 독립 실행해 확인한 것으로 표시하지 않음.
- Tunç(2020)·Abdo(2023)는 평가문항·정답·보고서의 참고문헌으로 확인됨. 해당 논문 원문 PDF 자체는 현재 파일 목록에서 찾지 못했으며 L01의 자료 정리 과제에 포함함.
- 11/24 분석 보고서가 설명한 임시 시나리오 파일 일부는 현재 목록에 없음. 존재하지 않는 과거 버전을 직접 읽었다고 표시하지 않음.
- 현재 원본·결과표의 핵심 수치를 대조했으며 전체 분석을 다른 환경에서 새로 실행한 재현성 연구는 수행하지 않음.

## 평가·산출물 해석에 미치는 영향

- 파일이 많아도 대부분 분석 코드·CSV·그림·해설·중복 표현임. ‘289개=289번의 독립 실험’으로 해석하지 않음.
- 기존 분석은 이미 충분한 산출물을 갖췄으며, 남은 핵심은 데이터 품질 한계의 관리와 앱·계산·평가의 실제 연결임.
- `source_manifest.csv`의 review_level과 read_limit이 파일별 검토 수준의 기준임.
