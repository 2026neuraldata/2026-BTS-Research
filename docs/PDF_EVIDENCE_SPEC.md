# 최적화 결과·탄소 증빙 PDF 설계

- 선행 작업: 🟢 E03, 김선우·임수현 공동, 11/28–11/29.
- 구현: 🟠 C06, 허재영, 11/30–12/1.
- 목표: LLM 추천 조건과 계산 근거를 보존하고, 해당 제도의 보고·검증에 재사용할 수 있는 문서·데이터 묶음 구성.

## 제도별 조사 범위와 활용 판단

| 대상 | E03에서 확인할 내용 | 현재 연구 결과의 활용 방향 | 직접 활용에 필요한 조건 |
|---|---|---|---|
| CBAM | 적용 품목·시설·보고기간, 내재배출량 산정 경계, 현행 보고 항목·전자 제출 절차·검증보고서 | 대상 생산시설과 연결되는 경우 공정 활동자료·계산 근거의 보조 증빙 | 적용 대상과 배분 근거 확인, 요구 활동자료 확보, 실제 배출량 사용 시 적격 독립 검증 및 정식 신고 절차 |
| RE100 | 전력 소비량·재생전력 조달량, 계약·에너지 속성 인증서 및 소유·취소 증빙, 시장·기간 요건 | 전력 사용량 및 근거 정리 부록 | 재생전력 속성과 해당 소비의 연결 증빙. 에너지 효율 향상이나 약품 탄소 절감만으로 재생전력 사용 입증 불가 |
| ISO | 조직 배출량 ISO 14064-1, 감축 프로젝트 14064-2, 검증·타당성평가 14064-3, 제품 탄소발자국 14067 중 목적에 맞는 범위 | 선택한 기준의 활동자료·산정 근거·검토 기록으로 연결 | 해당 표준의 상세 요구와 적용 프로그램 확인, 충분한 자료 및 독립 검증 절차. ISO 전체를 포괄하는 단일 인증 PDF로 취급하지 않음 |

- 위 활용 방향은 공식 자료를 연구 상황에 적용한 설계 판단. 우리 연구의 수처리 최적화가 자동으로 CBAM 대상이 되는 것은 아님.
- E03 비교표 열: 제도/공식 문서명/버전/URL/항목·페이지/제출 형식/필수 증빙/우리 데이터/누락 자료/직접·간접·적용 불가/판단 이유.
- 전환기 양식을 현행 CBAM 신고 양식으로 혼용하지 않도록 적용 기간 확인. 공식 제출이 포털·스프레드시트라면 PDF는 설명·첨부 자료로 설계.
- ISO 공개 소개 자료는 목적·적용 범위 확인에 사용. 유료 표준 전문의 조항별 적합성은 현재 검토하지 않았으므로 E03에서 확보 가능 여부와 확인하지 못한 조항을 기록.

## 11/29 제출할 실제 PDF 예시 3종

| 예시 | 핵심 내용 | 제작 담당 |
|---|---|---|
| 01 최적화 결과 보고서 | 시료·조건 ID, 추천 pH·투입량, 선정 목표·규칙, 적용 범위, 기준 대비 결과, 관측/추정 구분, 근거 링크 | 선우 작성 |
| 02 탄소 계산 근거서 | 보고기간·기능단위·경계, 기준/추천 활동자료, 전력·약품별 계수 출처와 버전, 수식·단위·불확실성·누락값, CSV/JSON 연결 | 수현 작성 |
| 03 제도별 증빙·검증 부록 | CBAM/RE100/선택 ISO별 항목 대응표, 원자료 목록, 전력 조달 증빙 참조란, 작성·수정 이력, 외부 검증보고서 연결란 | 공동 작성, 재영에게 인계 |

- 기존 실험 자료와 명확히 표시한 계산 예시만 사용. 존재하지 않는 계측값·계약·인증서·검증기관 서명은 생성하지 않음. 미확보 값은 공란과 필요한 자료명 표시.
- 추천 시나리오의 예상 차이와 실제 측정한 보고기간 배출량을 별도 표로 분리.
- PDF 외에 편집 가능한 원본과 필드 명세 제출. 3종은 하나의 통합 PDF에서 본문·부록으로 묶을 수 있도록 공통 report_id 사용.

## AI 생성 문서의 신뢰성 확보 기술

아래는 C06에 적용할 설계 항목이며, 구현 완료 상태가 아님.

| 기능 | 확인할 수 있는 것 | 범위·한계 | 일정 내 처리 |
|---|---|---|---|
| 원자료 ID·행·파일 SHA-256 및 파일 목록 | 어떤 원본에서 결과가 생성됐는지, 이후 파일 변경 여부 | 원본 측정값 자체의 진실성을 보증하지 않음 | C06 필수 |
| 코드 기반 계산과 CSV/JSON 부록 | 수식·단위·반올림·결과 재계산 | LLM 문장만으로 수치 확정하지 않음 | C06 필수 |
| 모델·프롬프트·코드·계수 버전과 실행 시각 | 사용한 처리 과정과 입력의 추적 | 모델 재호출의 동일 답변까지 보장하지 않으므로 원 응답도 보존 | C06 필수 |
| 작성·수정 이력·접근 권한 | 작성자·변경 사유 | 작성 이력과 독립기관 검증은 별도 상태 | C06 필수 |
| PDF 디지털 서명·신뢰할 수 있는 타임스탬프 | 서명자 및 서명 후 변경, 시점 확인 | 인증서·키 관리 필요. 문서 내용의 정확성이나 탄소 인증을 대신하지 않음 | E03 비용·도구·기관 요구 검토 후 도입 범위 결정 |
| 변경 방지 저장·접근 통제·장기 보존 | 증빙의 보존과 접근 이력 | 해시 목록 자체도 보호 필요 | E03 기존 저장소 활용과 추가 비용 비교 |
| 계측기 교정 기록·현장 원장·독립 검증보고서 연결 | 실측의 품질과 검증 범위 | 소프트웨어만으로 만들어낼 수 없는 외부 근거 | 기존 자료 연결, 미확보는 누락 표시 |

- 블록체인은 필수 전제에서 제외. 해시·서명·타임스탬프와 비교해 추가 효용이 있는 경우만 검토.
- 실제 기관이 발행한 검증 의견은 원본 그대로 별도 연결. AI가 검증 완료 상태나 검증기관 서명을 자동 생성하는 기능은 포함하지 않음.
