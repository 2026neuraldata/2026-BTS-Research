# GitHub 운영 설정

- 계정: 2026neuraldata임. 표시 제목: 2026 BTS Research, 저장소명: 2026-BTS-Research임.
- 연구 운영 내용과 내부 Drive 링크가 포함되어 비공개로 생성하는 안임.
- 사용자 계정 인증·권한이 확인된 연결에서만 업로드함. 이메일 주소만으로 로그인 권한을 얻을 수 없음.
- 기본 branch는 main임. 기존 동명 저장소가 있으면 새 내용을 덮어쓰기 전에 실제 내용을 확인해야 함.
- README, PROGRESS, docs/TEAM_TASKS가 탐색 진입점임. Issue 템플릿은 작업 ID와 연결하는 선택 기능임.
- 현재의 tasks.csv를 업무 기준으로 유지함. Issue와 별도로 서로 다른 마감·상태를 이중 관리하지 않음.
- 참고 저장소는 Markdown 중심으로 일정·담당·인수인계를 관리함. GitHub Projects 보드를 그대로 복제한 것은 아님.
- 팀원 계정명을 확인한 후 필요한 협업 권한을 부여할 수 있음. 미확인 계정에 초대를 발송하지 않음.
- 원본 교재·녹음·시험 정답은 외부 공개 저장소에 복사하지 않음. 본 관리 패키지는 원문 링크와 검토 기록 중심임.
