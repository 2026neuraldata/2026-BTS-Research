# 담당별 작업과 제출물

- 기간 표기: 시작일–종료일(월/일). 연도: 2026.
- 12/7–12/18 및 12/23–12/27에는 작업을 배정하지 않음.
- **공통 제출 규칙:** 모든 업무의 제출물을 해당 업무 기간 내 BTS 카카오톡 단체방에 제출함.
- **제출 형식 준수:** 각 업무에 명시된 제출 파일 형식(CSV, JSON, PDF, MD 등) 및 필수 제출물 구성을 반드시 준수해야 함.
- **진행 관리 규칙:** 김선우가 제출물의 형식 준수 여부 및 연구 진행 상황을 검토하고 GitHub를 업데이트함.
- **업무 의존성 유지:** 특정 팀원의 결과물이 후속 업무에 필요한 경우 기존 선행 작업 및 인계 관계를 유지함.
- **제출 대상자:** 공통 제출 경로를 사용하므로 별도로 지정하지 않음.
- **비공개 자료 보호:** 정답표·보정 데이터·사람 점수는 BTS 카카오톡 단체방 내부에서만 공유하며 공개 GitHub와 평가 대상 LLM의 검색 자료에서 제외함. API 키는 제출 파일에 포함하지 않음.

**핵심 운영 원칙:** 제출 기한 준수 · 제출 형식 엄수 · 제출 경로 일원화
