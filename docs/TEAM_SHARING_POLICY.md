# 팀 내부 산출물 공유 및 평가자료 활용 주의사항

- 모든 산출물은 해당 업무 기간 내 BTS 카카오톡 단체방에 공유함. 평가자료는 연구 이해 및 평가 설계 검토 목적으로 팀원이 자유롭게 열람할 수 있으나, 최종 평가문항 및 정답자료를 평가 대상 LLM의 개발·최적화·성능 개선에 사용하지 않음. 비공개 평가자료의 외부 공개·공개 GitHub 업로드 금지. 후보 LLM/RAG에 전체 문항·Gold·채점자료 입력 금지. 평가 시 후보에게 현재 문항 1개만 제공함. API 키 등 자격증명은 공유본에서 제외함.
- 실제 개발·튜닝·선정·보정에 사용된 문항/문제군만 사용 이력으로 확인하며 단순 열람을 개인별로 기록하지 않음. 최종 문항이 개발에 사용된 경우 개발셋 평가로 표시하고 독립 시험이라고 주장하지 않음.
- 팀 내부 회의에서 개별 평가자료를 확인할 수 있음. 외부 공개 자료·회의록에는 공개 가능한 집계와 오류 유형만 사용함. 독립 인간 채점은 모델명 및 심사위원 점수를 보지 않은 상태에서 완료하고 해당 결과를 공유함.
- 승인된 심사위원 실행 단계에서만 채점에 필요한 Gold를 제공하며, C05는 별도 보정/검증용 승인 자료만 사용함. 후보 실행 계정·검색 DB·API 세션에는 공유 ZIP을 연결하지 않음. 원문 문헌은 팀이 합법적으로 열람할 수 있는 범위에서만 공유함.
- 비공개 평가자료의 외부 공개는 별도 승인 전까지 평가 종료 후에도 금지함. 기존 접근통제 검증, 모델 설정 동결 및 문제군 분리 기준은 유지함.
