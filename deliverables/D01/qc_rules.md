## 1. Jar Test

- 총 24개 조건 = 언양·굴화 각각 12조건(목표 pH 5/7/9 × 실제 FeCl3 투입량 20.10/40.20/60.30/80.16 mg/L). 각 설계조건별 Jar 관측 1회. 중복 조건 없음.
- 5분·30분은 동일 비커의 시간별 관측이며 독립 실험 반복이 아님. 원본 행 번호를 보존함.
- 실제 시료 부피 0.5 L와 초기 계획 1 L, 실제 dose와 명목 dose level을 구분함. 목표 pH와 조정 후 실측 pH도 구분함. 24/24 조건이 원본 기준 ±0.2 이내임. 실제 dose는 (stock 제조에 사용한 시약 질량 mg / stock 최종 부피 mL) × stock 투입 부피 mL / 원수 부피 L로 산출한 값이며 무수 FeCl3 환산 기준·수화물 여부·순도는 미확인임.
- 제거율(%) = 100 × (원수 NTU − 시점별 NTU)/원수 NTU. 초기 NTU가 0 이하이거나 결측이면 계산하지 않고 표시함. 변화량의 단위 %p와 NTU를 혼동하지 않음. 현재 24조건의 저장 제거율을 원본 값으로 재계산해 일치 확인함.
- 결측 또는 비정상값을 임의로 0, 계획값, 보간값으로 대체하지 않음. 원본 메모와 품질 진단을 보존하고 QC flag 변경 이력을 기록함. 원본 Jar Test 행 10(측정 중 흔들림), 27(덩어리 부유)을 별도 플래그로 표시하되 자동 제외하지 않음. 실험일 4/24 기록, 채수일 및 원본 교반·산염기 입력 미기록. D02에는 아래 E02 추가 확인값을 구분하여 반영함. 개별 비커 산·염기 사용 여부와 투입량은 여전히 미확인임. 누락은 0이 아님.
- 추천은 지역·시간·응집제·목표 탁도·실험 범위를 고정한 관측 후보 중 최소 dose를 원칙으로 함. 목표 미충족 및 관측 범위 밖에서는 추가 Jar Test 필요로 표시. 최소 dose와 총비용/탄소 최소는 다름. 초기 NTU ±30%는 현재 앱 휴리스틱이며 검증된 유사성 범위가 아님.

## 2. TS/VS

- 굴화 원수 2개 기록 + 처리 12조건 × 독립 반복 2회 = 26기록. 언양 TS/VS 없음. Jar와 TS/VS는 동일 설계조건 단위로만 연결하며 동일 비커의 직접 반복으로 해석하지 않음.
- TS(g/L) = (건조 후 질량 − 빈 접시 질량)/시료 부피(L), VS(g/L) = (건조 후 질량 − 강열 후 질량)/시료 부피(L). 모든 기록 재계산 대조 통과.
- 물리적 질량 관계 기준: TS>0, VS≥0, TS≥VS(수치 오차 허용 1e−9 g/L). 통과 5/26, VS>TS 21/26, 음수 TS 2/26 및 0 TS 1/26(모두 21건에 포함). 유효한 VS/TS 무차원 비율(0–1)은 5개 기록에서만 산출하며 대표값으로 일반화하지 않음.
- 음수 TS 또는 VS>TS를 삭제·역산·교체·보간하지 않음. 원인과 VS 자체의 분석 정확성은 미확정임. VS는 기록된 강열 감량을 반영하는 탐색 지표로만 사용함. TS·VS 모두 운영 추천 목적함수에서 제외함.
- VS 반복 표준편차(SD)는 표본 SD(ddof=1), 변동계수(CV, %)는 평균>0인 경우 100×SD/평균. n=2 기술통계로 해석하며 통계적 재현성 보증으로 표현하지 않음.
