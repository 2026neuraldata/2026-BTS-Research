# L02 통합 비교 설계
2026-11-28 설계 인계 완료. 실제 API·접근통제·노출 이력·심사 설정 동결 전 최종 실행 금지. B/C 동일 원자료와 실제 조회 가능성 검증; 검색 결과 차이는 시스템 효과의 일부. 문항·Gold·split·루브릭은 비공개. 공개 설정은 동결된 실행 설정이 아님.

- 모든 산출물은 해당 업무 기간 내 BTS 카카오톡 단체방에 공유함. 평가자료는 연구 이해 및 평가 설계 검토 목적으로 팀원이 자유롭게 열람할 수 있으나, 최종 평가문항 및 정답자료를 평가 대상 LLM의 개발·최적화·성능 개선에 사용하지 않음. 비공개 평가자료의 외부 공개·공개 GitHub 업로드 금지. 후보 LLM/RAG에 전체 문항·Gold·채점자료 입력 금지. 평가 시 후보에게 현재 문항 1개만 제공함. API 키 등 자격증명은 공유본에서 제외함.

- 11/28 회의 반영: DSPy 제외, C05 수동 설정 동결 유지. 신규 논문·전국 시설 자료는 운영용으로 분리하며 평가 B/C 허용 네 원자료 및 해시는 유지. 내부 선정/검증 자료는 팀 공유하되 후보 실행 환경에서 격리함.
