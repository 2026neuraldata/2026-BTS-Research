# L01 제출 확인
2026-11-28 통합 수정본의 평가문항·Gold·출처 매핑은 팀 내부 단체방 공유 전용. 실험 10 + 문헌 10, 기존 2점 체계 유지. 공개 저장소는 제출 확인 manifest만 포함. 문항 제작/검토 완료이며 독립 평가와 실제 실행은 미확정. 후보 모델에는 현재 문항 한 개만 제공함.

- 별도 공개 승인 전까지 평가 종료 이후에도 전체 문항·정답·출처 매핑·문항별 루브릭은 비공개로 유지함.

- 평가자료는 연구 이해 및 평가 설계 검토 목적으로 팀원이 자유롭게 열람할 수 있으나, 최종 평가문항 및 정답자료를 평가 대상 LLM의 개발·최적화·성능 개선에 사용하지 않음. 외부 공개 및 후보 LLM/RAG 입력 금지.
