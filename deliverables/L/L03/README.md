# L03 잠정 심사위원 제공사 선정
- Gemini 주 / GPT 교차 / Claude 예비. 실제 API 모델 ID와 호출 설정 미확인.
- 10개 질문, 실제 답변 30개, 수동 웹 채팅 결과로 가져온 판정 90개. 기준 점수는 LLM 보조 후 사람 승인으로 독립 채점 아님.
- 기준 점수 분포 2점 29건, 1점 1건, 0점 0건. 무조건 2점도 96.67% 일치. 일반화 및 독립 오류 검출 능력 입증 아님.
- Gemini MCQ MAE 0 / 일치율 100% / G-Eval MAE 0.0889. GPT 0.1000 / 90% / 0.1111. Claude 0.0333 / 96.67% / 0.1778. 교차 제공사 선택은 품질 및 오류 민감도 중시의 잠정 판단임.
- 실패 0은 제출된 판정 데이터의 유효성 기준이며 API 실패율 아님. 비용/시간/모델 ID 미확인. L05 별도 보정·C05 설정 동결 필요.
- 공개 helper는 내부 원본을 가진 팀원이 로컬에서 검산하는 도구임. 원본 점수는 수정하거나 덮어쓰지 않음.

- L05 독립 인간 채점·선정/검증 자료와 추가 비교 집계(미실행 사유 포함)를 확인하고 C05 실제 수동 프롬프트·모델 설정·루브릭·선정 근거·해시를 최종 답변 열람 전에 동결함. DSPy는 11/28 회의에서 제외 확정. C03/L04 실제 API·접근통제·형식 및 실제 개발 활용 검토 미통과 시 L06 실행 금지. L07은 L06의 동일 저장 응답만 사용함.

- 모든 산출물은 해당 업무 기간 내 BTS 카카오톡 단체방에 공유함. 평가자료는 연구 이해 및 평가 설계 검토 목적으로 팀원이 자유롭게 열람할 수 있으나, 최종 평가문항 및 정답자료를 평가 대상 LLM의 개발·최적화·성능 개선에 사용하지 않음. 비공개 평가자료의 외부 공개·공개 GitHub 업로드 금지. 후보 LLM/RAG에 전체 문항·Gold·채점자료 입력 금지. 평가 시 후보에게 현재 문항 1개만 제공함. API 키 등 자격증명은 공유본에서 제외함.
