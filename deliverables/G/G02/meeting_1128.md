# 11/28 회의 기록

- 기록 근거: [사용자 제공 수정지침서](../../../docs/MEETING_REVISION_GUIDE_20261128.pdf)의 회의 결정·관찰 요약. 원 회의 메모는 이번 첨부에 없어 별도 확인하지 않음.
- 참석자·시간·장소: 미기재. 실제 API 모델·버전·권한 및 공식 포스터 전체 규격: 미확인.

## 회의 결정 6개

1. 문헌 dosage 미출력·pH 7 반복을 보완. 직접 문헌값과 근거 있는 추정 분리, 논문2 원문 확인, 기존 실험 회귀시험 유지.
2. 언양·굴화 및 전국 시설별 현황·원수 해석/예측 시각화와 앱 새 칸 추가. 실제 확보 자료·가정·미확보 구분.
3. QR 및 컴퓨터 시연 모두 사용. URL·권한·API·외부 접속·백업은 G03/C07/P06에서 확인.
4. 연구팀 실험 기준 가정별 에너지·탄소 case 제시. 현장 실측 절감량으로 주장하지 않음.
5. CBAM·RE100·ISO PDF는 산정 근거·보조 증빙으로만 활용. 직접 증빙·공식 인증 불가.
6. DSPy 제외. 독립 인간 채점·추가 심사위원 비교·수동 프롬프트 동결은 유지.

## 관찰과 남은 작업

- 실험 추천은 정상이라고 보고됨. C02 회귀시험 완료를 의미하지 않음. 문헌 dosage·pH 원인은 실제 로그로 확인 필요.
- 논문2 제목·DOI·버전·원문 미확인. 운영 자료가 늘어도 평가 B/C 허용 네 파일은 유지.
- 제품/활성성분·전력·산염기 투입량·LCA 계수의 미확인 항목 유지. E01/E02 원본 수치 보존.
- L03 Gemini 주·GPT 교차·Claude 예비는 잠정. 실제 API·접근통제·L05 비교·C05 고정 전 L06 금지.
- G02 완료는 회의 실시·기록 확보를 의미하며 구현·검증·최종 평가 완료가 아님.
- P01 계획·배치 제출 완료. [계획 PDF](../../P/P01/poster_layout.pdf) 원본 보존; 공식 전체 규격·제출 형식은 P03 출력 전 확인. 292 mm × 160 mm는 사진 영역.

## 회의 이후 업무 배정 승인

- 사용자 승인에 따라 D04 김선우 11/29–11/30(선행 D03), C08 허재영 12/1–12/2(선행 D04·C02) 정식 등록. 회의 원문에서 확정된 배정으로 소급하지 않음.
- G03 실행 가능 범위 확인, G04 실제 확보 결과만 채택. 기존 업무 마감·휴식 기간 유지.
