## 4. 11/28 회의 안건

**회의 목적:** 연구 범위와 평가·앱 구현 준비 상태를 확인하고, 11/29 예행연습에 앞서 남은 오류의 담당 및 해결 기한을 정함. 아래는 질문과 결정 후보이며 회의에서 확정하기 전까지 완료로 간주하지 않음.

| 안건 | 확인할 질문 | 회의에서 남길 결정·기록 |
|---|---|---|
| 1. 연구 범위 | 추가 실험 없이 기존 자료로 추천·문헌·에너지·LLM 평가를 진행할 것인가? | 필수/조건부/보류 범위 (DEC01) |
| 2. 실험 데이터 | D01/D02 기준본을 모두 같은 버전으로 사용하고 있는가? TS/VS를 추천에서 제외했는가? | 기준 경로·해시, 24조건/26기록 및 해석 제한 |
| 3. 추천 기능 | 동일 지역에서 목표 탁도를 만족하는 최소 실제 투입량을 찾는가? 자료 없는 조건은 거절하는가? | 지역 범위·동률 규칙·문헌 페이지 표시·오류 해결일 (DEC03/C02) |
| 4. 에너지·탄소 | 계산에 필요한 값과 배출계수는 확보됐는가? 누락값·FeCl3 질량 기준은 어떻게 처리하는가? | 실제 전력·약품 탄소·전력환산 구분, 가정·단위·경계 (DEC04) |
| 5. 비교 평가 | 20문항의 정답·근거와 3개 비교 조건이 확정됐는가? | 모델 ID/설정·채점 규칙·원문 확인 상태·실패 처리 (DEC05/L01/L02) |
| 6. 심사위원 | GPT·Claude·Gemini 중 어떤 모델을 어떤 근거로 선정했는가? | 주·교차 심사위원 모델 ID/버전·선정 근거·미실행 후보 (DEC11/L03) |
| 7. 앱 및 답변 수집 | C01 코드와 배포 버전이 일치하는가? C02/C03 기능이 실행되는가? | 코드·실행 로그·API 모델 ID·미완료 및 오류별 담당/해결일 |
| 8. 포스터 | 공식 크기·파일 형식·인쇄 조건을 확인했는가? | 규격(미확인 시 미확정), 결과 영역 배치 (DEC08/P01) |
| 9. 결과 통합·PDF | 결과와 코드의 통합 책임 및 탄소 증빙 PDF의 구현 범위는 무엇인가? | 문서·그림·결과: 김선우 / 앱 코드: 허재영. E03 조사·예시 범위 확인 (DEC07/DEC10) |

### 평가·개발 확인 시 지켜야 할 기준

- 비교 3조건: 추가 자료 없는 일반 LLM(참고용), 동일 자료를 제공한 일반 LLM, 응집 전문 LLM 시스템. 공정한 비교를 위해 동일 기반 모델·공통 자료 조건을 고정함.
- 20문항: 실험 10 + 문헌 10. 정답 1점·근거 1점. Tunç/Abdo 원문 미확인 문항은 임의 삭제·교체·정답 확정 금지, 처리 방안 합의. 정답·사람 점수·보정 자료 비공개.
- 심사위원 후보 선정: 최종 평가와 분리된 실제 답변 최소 12개에서 사람 점수 대비 평균 절대 오차(MAE)·일치율·비용·실패율·자기 모델 선호 비교. 미실행 후보 명시.
- DSPy는 11/29에 적용 가능성을 잠정 논의하고 L05 독립 보정 자료 확보 후 결정함. 자료 부족 시 수동 심사위원 프롬프트 고정·사람 채점 유지. 최종 평가 답변을 프롬프트 최적화에 사용하지 않음(DEC06).
- 에너지 절감량은 실측 여부에 따라 구분하고, 문헌 가정으로 산출한 시나리오는 실측 절감으로 표현하지 않음.
